# Учебный проект: тестирование (pytest)

## Структура

- `src/` — функциональный код
  - `masks.py` — маскирование карт/счетов
  - `widget.py` — функции виджета (маска + дата)
  - `processing.py` — фильтрация/сортировка операций
- `tests/` — тесты (по одному файлу на модуль)

## Установка (PyCharm / Windows)

1. Откройте папку проекта `d:\Curcor\Учеба` в PyCharm.
2. Создайте виртуальное окружение (PyCharm предложит автоматически).
3. Установите зависимости для разработки:

```bash
python -m pip install -r requirements-dev.txt
```

## Запуск тестов

Запуск всех тестов:

```bash
pytest
```

По умолчанию включено покрытие (см. `pyproject.toml`): вывод в консоль и HTML‑отчет.

## Отчет покрытия (HTML)

После запуска `pytest` создается папка:

- `htmlcov/` — HTML‑отчет покрытия, открыть файл `htmlcov/index.html` в браузере.
